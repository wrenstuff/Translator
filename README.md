# Translator
205.2 group project


NeoBabel is a speech-translation AI system, designed to translate a spoken input into a spoken output. The system will listen to a user's voice, transcribe it into text, and output the translation of the target language using text to speech.​

Unlike traditional translation platforms that rely on text input for translation, NeoBabel is designed with a speech-first approach, and aims to implement languages of communities which have little to no language documentation.​

Installing Project:

Clone repository using https://github.com/wrenstuff/Translator.git

** DO NOT USE 'DOWNLOAD ZIP' AS THIS WILL NOT WORK **

Once cloned Install requirements using: pip install -r requirements.txt
